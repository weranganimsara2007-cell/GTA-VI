## 🚀 Quick Start Guide

```bash
# 1. Clone the repository
git clone https://github.com/weranganimsara2007-cell/WeraXX-main.git

# 2. Navigate to project directory
cd WeraXX-main

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev

# 5. Build for production (single-file bundle)
npm run build
```
